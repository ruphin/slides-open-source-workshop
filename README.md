#### Slides

To see the slides, clone this repository and run the following commands

```
npm install
npm run dev
```

Then you should be able to see the slides on `localhost:5000`.
Navigate with left and right arrow keys.

To build a static version of the slides into `dist/`, run `npm run build` (preview it with `npm run preview`).
`npm run docker` builds a Docker image that serves `dist/` with nginx.
